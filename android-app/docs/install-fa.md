# نصب، اجرا و به‌روزرسانی

این سند فقط کارِ «نصب و استفاده» است. برای شناخت قابلیت‌ها به [`README-fa.md`](README-fa.md) و برای
خطاهای احتمالی به [`troubleshooting-fa.md`](troubleshooting-fa.md) مراجعه کنید.

---

## ۱) کدام فایل را دانلود کنم؟

از صفحهٔ [Releases](https://github.com/animalrender/Myvpn/releases) آخرین نسخه (بالاترین شماره،
مثلاً `trial-51`) را باز کنید. هر انتشار **چهار فایل** دارد:

| فایل | معماری | برای چه کسی |
| --- | --- | --- |
| `mvpn-trial-arm64-<N>.apk` | `arm64-v8a` | گوشی و تبلت اندرویدی (تقریباً همهٔ دستگاه‌های امروزی) |
| `mvpn-trial-x86_64-<N>.apk` | `x86_64` | شبیه‌ساز اندروید (AVD)، کروم‌بوک، برخی ماشین‌های مجازی |
| `mvpn-trial-arm64-<N>.apk.sha256` | — | بررسی صحت دانلود |
| `mvpn-trial-x86_64-<N>.apk.sha256` | — | بررسی صحت دانلود |

پیش‌نیازها:

- اندروید **۷٫۰ (API 24)** یا بالاتر
- اتصال اینترنت برای دریافت فهرست سرورها (خود اپ چیزی از شما نمی‌پرسد)
- دسترسی به «شبکهٔ خصوصی مجازی (VPN)» که اندروید بار اول می‌پرسد

```bash
gh release download trial-51                    # هر دو APK + sha256
sha256sum -c mvpn-trial-arm64-51.apk.sha256     # باید OK بدهد
```

روی گوشی هم می‌توانید فایل APK را مستقیم دانلود کنید؛ اندروید برای نصب از فایل، اجازهٔ
«نصب برنامه‌های ناشناس» برای مرورگر/فایل‌منیجر می‌خواهد.

---

## ۲) بررسی امضا (اختیاری ولی توصیه‌شده)

APK با **AOSP testkey** امضا شده است؛ همان گواهی نسخهٔ اصلی. این کار عمدی است، چون بک‌اند
امضای برنامه را با هدرهای `sign` و `sha_hexadecimal` می‌سنجد.

```bash
apksigner verify --print-certs mvpn-trial-arm64-51.apk
# SHA-256 گواهی باید a40da80a59d170caa950cf15c18c454d47a39b26989d8b640ecd745ba71bf5dc باشد
```

اگر گواهی چیز دیگری بود، فایل از منبع دیگری آمده است؛ آن را نصب نکنید.

## ۳) نصب

### روی گوشی واقعی

1. فایل `arm64` را به گوشی منتقل کنید (کابل، Google Drive، Telegram…).
2. روی فایل بزنید و «نصب» را تأیید کنید.
3. اگر اندروید پیام «برای امنیت، نصب برنامه از این منبع مجاز نیست» داد، برای همان
   مرورگر/فایل‌منیجر «نصب برنامه‌های ناشناس» را روشن کنید و دوباره تلاش کنید.

### با adb (شبیه‌ساز یا گوشی با USB Debugging)

```bash
adb devices                                   # دستگاه باید در حالت device باشد
adb install -r mvpn-trial-arm64-51.apk        # -r = به‌روزرسانی روی نسخهٔ قبلی همین اپ
```

روی شبیه‌ساز حتماً فایل `x86_64` را نصب کنید؛ نصب `arm64` روی AVD خطای
`INSTALL_FAILED_NO_MATCHING_ABIS` می‌دهد.

### نصب کنار اپ اصلی (بدون حذف آن)

شناسهٔ این نسخه `co.asiven.vixentvpn.trial` است، در حالی که اپ اصلی `co.asiven.vixentvpn` است.
پس:

- هر دو اپ **هم‌زمان** نصب می‌مانند و آیکون جدا دارند؛
- لازم نیست اپ اصلی را حذف کنید و تنظیمات/اشتراک‌هایش دست‌نخورده می‌ماند؛
- هدر `app_name` که بک‌اند می‌شناسد همان `co.asiven.vixentvpn` می‌ماند، پس پاسخ بک‌اند یکسان است.

اگر نسخهٔ قدیمیِ همین **اپ آزمایشی** را دارید، `adb install -r` (یا نصب معمولی) آن را به‌روز
می‌کند. اگر پیام `INSTALL_FAILED_UPDATE_INCOMPATIBLE` دیدید یعنی APK فعلی با امضای دیگری نصب
شده است؛ یک‌بار حذف و دوباره نصب کنید:

```bash
adb uninstall co.asiven.vixentvpn.trial
adb install mvpn-trial-arm64-51.apk
```

## ۴) اولین اجرا

1. اپ را باز کنید. اجازهٔ اعلان (اندروید ۱۳+) را بدهید؛ برای نمایش وضعیت تونل استفاده می‌شود.
2. فهرست سرورها **خودکار** از بک‌اند می‌آید؛ نوار خلاصه باید چیزی شبیه
   `نمایش 105 از 105 سرور (رایگان: 105 / پولی: 0)` نشان دهد. (اگر یک بار پاسخ خالی بیاید،
   اپ خودش بی‌سر‌و‌صدا دوباره درخواست می‌زند.)
3. اپ خودش «پینگ همه» را شروع می‌کند و سریع‌ترین سروری که واقعاً پاسخ داده را انتخاب می‌کند.
4. دکمهٔ **اتصال** را بزنید ← اندروید دیالوگ «درخواست اتصال» (VPN) را نشان می‌دهد ← تأیید کنید.
5. وضعیت ابتدا «در حال اتصال…» و بعد «در حال آزمایش عبور ترافیک…» می‌شود. فقط اگر یک درخواست
   واقعی از تونل عبور کند، «متصل — <نام سرور> (VPN)» نمایش داده می‌شود.
6. برای تغییر سرور: ردیف دیگری را لمس کنید؛ دکمه به «اتصال به سرور انتخابی» تغییر می‌کند و
   یک لمس تونل را روی سرور تازه می‌آورد. برای قطع، وقتی همان ردیف متصل انتخاب است،
   دکمه «قطع اتصال» است.

> اگر پیام «ترافیک از تونل عبور نکرد؛ این سرور پاسخ نداد» دیدید: آن ردیف در آن لحظه مرده است.
> اپ عمداً تونل را نمی‌بندد-نمی‌گذارد و «متصل» دروغین نشان نمی‌دهد؛ سرور دیگری را امتحان کنید.

## ۵) حالت‌های اتصال

| حالت | چه می‌کند | کِی به کار می‌آید |
| --- | --- | --- |
| `VPN` (پیش‌فرض) | TUN سراسری؛ همهٔ ترافیک دستگاه از تونل می‌رود | استفادهٔ روزمره |
| `PROXY` | بدون TUN؛ فقط `SOCKS 127.0.0.1:10808` و `HTTP 127.0.0.1:10809` | وقتی می‌خواهید فقط یک برنامه از پروکسی استفاده کند |

در حالت `PROXY` می‌توانید از داخل دستگاه تست کنید:

```bash
# از پوستهٔ adb (اگر ابزار curl/nc دارید)
nc -X 5 -x 127.0.0.1:10808 1.1.1.1 80
```

## ۶) به‌روزرسانی و حذف

```bash
gh release list                          # نسخهٔ جدیدتر؟
adb install -r mvpn-trial-arm64-<N>.apk  # به‌روزرسانی بدون از دست دادن تنظیمات
adb uninstall co.asiven.vixentvpn.trial  # حذف فقط نسخهٔ آزمایشی
```

- حذف این اپ روی اپ اصلی و تنظیماتش اثری ندارد.
- تنظیمات این اپ (انتخاب سرور، مرتب‌سازی، توکن) در `SharedPreferences` با نام `mvpn_trial`
  ذخیره می‌شود و با حذف اپ پاک می‌شود.

## ۷) استفاده از لینک‌ها در v2rayNG / nekobox

اگر می‌خواهید همین سرورها را در کلاینت دیگری داشته باشید:

1. در اپ: منوی سه‌نقطه ← **«کپی همهٔ لینک‌های v2ray»** ← یکی از سه گروه
   (همه / پینگ‌داده‌ها / بی‌پینگ‌ها).
2. در v2rayNG: **Import config from clipboard** (هر خط یک کانفیگ است).
3. برای یک سرور خاص: ردیف ← bottom sheet ← «کپی لینک v2ray».

مقایسهٔ کامل «اپ ترایال یا v2rayNG» در [`README-fa.md`](README-fa.md) بخش پرسش‌های متداول آمده است.
