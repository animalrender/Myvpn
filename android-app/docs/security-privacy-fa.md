# امنیت، حریم خصوصی و مجوزها

این سند دقیقاً می‌گوید این اپ چه داده‌ای می‌فرستد، کجا ذخیره می‌کند، چه مجوزهایی می‌گیرد و
مسئولیت اعتماد به کدام بخش است.

---

## ۱) چه چیزی حذف شده است

| حذف‌شده | یعنی چه |
| --- | --- |
| SDKهای تبلیغاتی (Admob / FairBid / native / interstitial / reward) | هیچ کتابخانه یا شناسهٔ تبلیغاتی در APK نیست و هیچ درخواست تبلیغاتی ارسال نمی‌شود |
| حساب کاربری و ورود | هیچ صفحهٔ ثبت‌نام/ورود، هیچ `email/password`، هیچ مدیریت دستگاه |
| منطق سکه/الماس و پرداخت | هیچ خرید درون‌برنامه‌ای، هیچ مصرف سکه، هیچ دروازهٔ `price` |
| تحلیل رفتار (analytics) اختصاصی | اپ خودش هیچ رویداد تحلیلی نمی‌فرستد |

Firebase Messaging **باقی مانده است** (طبق تصمیم پروژه، مثل اپ اصلی) — بخش ۴.

## ۲) داده‌ای که به بک‌اند می‌رود

تنها مقصد، همان بک‌اند خود اپ اصلی است: `https://managev1.xyz`.

| داده | چطور ساخته می‌شود | چرا |
| --- | --- | --- |
| `app_name` | مقدار ثابت `co.asiven.vixentvpn` (از `BuildConfig.HEADER_APP_NAME`) | بک‌اند بر اساس همین هویت جواب می‌دهد |
| `version_code` | مقدار ثابت `1004220` | همان نسخهٔ کلاینت اصلی |
| `seen` | `0` | پرچم «تبلیغ دیده شد» اپ اصلی؛ در این نسخه همیشه صفر |
| `sign` | `Base64(MD5(DER گواهی امضا))` | اثبات این‌که درخواست از یک APK با همان امضا آمده |
| `sha_hexadecimal` | `hex(SHA-256(SHA-256(DER)))` | همان بررسی، با هش دوم |
| `token` / `Authorization` | فقط اگر بک‌اند توکن داده باشد | در این بک‌اند توکن اپ غیرفعال است (`The app token is disabled`) |
| `deviceId` (در `/api/token`) | `Settings.Secure.ANDROID_ID` | همان شناسه‌ای که کلاینت اصلی می‌فرستد |
| `firebase_token` (در `/api/token`) | توکن FCM دستگاه | همان رفتار اپ اصلی |

**آنچه ارسال نمی‌شود:** مخاطبین، موقعیت مکانی، فهرست برنامه‌ها، IMEI/سریال، محتوای فایل‌ها،
تاریخچهٔ مرور. اپ هیچ دسترسی‌ای به این‌ها نمی‌گیرد.

## ۳) ذخیره‌سازی محلی

| داده | جا | عمر |
| --- | --- | --- |
| انتخاب سرور، مرتب‌سازی، حالت (`VPN`/`PROXY`)، توکن، `deviceId`, `firebase_token` | `SharedPreferences` با نام `mvpn_trial` | تا حذف اپ یا «پاک کردن داده» |
| کش آخرین پاسخ بک‌اند | همان `SharedPreferences` | برای نمایش فوری فهرست در اجرای بعدی |
| لاگ داخلی (`AppLog`) | حافظه (۸۰۰ خط) + فایل `filesDir/mvpn-trial.log` (حداکثر ~۵۱۲ کیلوبایت، چرخشی) | با حذف اپ پاک می‌شود |

لاگ‌ها می‌توانند شامل **نام/کشور سرورها و متن خطای هسته** باشند. اگر می‌خواهید لاگ را
منتشر کنید، اول یک بار «لاگ‌ها» را در اپ ببینید و اگر لازم بود فقط خطوط مرتبط را بفرستید.

## ۴) Firebase

| مورد | مقدار |
| --- | --- |
| پروژه | همان پروژهٔ اپ اصلی (`vixent-5ac3f`) — `android-app/app/google-services.json` |
| استفاده | فقط `firebase-messaging`: گرفتن توکن FCM و ارسال آن به‌عنوان `firebase_token` در `/api/token` |
| اگر Google Play Services نبود | خطا فقط لاگ می‌شود؛ اپ بدون Firebase هم کامل کار می‌کند |
| پیام‌های دریافتی | `TrialMessagingService` پیام را لاگ می‌کند و هیچ اکشن پولی/تبلیغاتی اجرا نمی‌کند |

اگر نمی‌خواهید Firebase فعال باشد، می‌توانید در `app/build.gradle.kts` پلاگین
`com.google.gms.google-services` و وابستگی `firebase-messaging` را بردارید؛ تنها اثرش این است
که `firebase_token` خالی می‌ماند.

## ۵) مجوزهای اندروید

| مجوز | چرا |
| --- | --- |
| `INTERNET` | دریافت فهرست سرورها و اتصال به سرور |
| `ACCESS_NETWORK_STATE` | تشخیص وضعیت شبکه برای پیام‌های خطا |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` (و `POST_NOTIFICATIONS` در اندروید ۱۳+) | اجرای پایدار تونل و نمایش وضعیت در نوار اعلان |
| `BIND_VPN_SERVICE` (سرویس VPN) | لازمهٔ ساخت رابط TUN؛ کاربر آن را در دیالوگ سیستم تأیید می‌کند |

اپ **هیچ‌کدام** از این‌ها را نمی‌خواهد: مخاطبین، پیامک، دوربین، میکروفون، موقعیت مکانی،
حافظهٔ خارجی، لیست برنامه‌ها.

## ۶) مدل اعتماد (مهم)

- **ترافیک شما از سرور واسط عبور می‌کند.** امنیت محتوای ترافیک به پروتکل (TLS/Reality) و به
  اپراتور سرور بستگی دارد؛ این اپ فقط تونل را برقرار می‌کند. برای کارهای حساس، همان
  قاعدهٔ «به VPN رایگان اعتماد کامل نکنید» برقرار است.
- **بک‌اند شخص ثالث است.** `managev1.xyz` همان بک‌اند اپ اصلی است و در کنترل این مخزن نیست؛
  فهرست سرورها و `value` از آن می‌آید.
- **کلید امضا در مخزن نیست.** `signing/` در `.gitignore` است و CI کلید AOSP testkey را
  از مخزن AOSP می‌سازد. این کلید عمومی است و برای «تطبیق با بک‌اند» استفاده می‌شود،
  نه برای محافظت از محتوا.
- **رمزگشایی `value` سمت دستگاه است** (AES/CBC با کلید `key_<id>`). این رمز، محافظت واقعی
  نیست؛ فقط قالب دادهٔ بک‌اند است. جزئیات: [`value-decrypt-fa.md`](value-decrypt-fa.md).

## ۸) چک‌لیست بررسی امنیتی برای بازبین

```bash
# ۱) مجوزهای APK
aapt2 dump permissions mvpn-trial-arm64-51.apk

# ۲) امضا
apksigner verify --print-certs mvpn-trial-arm64-51.apk

# ۳) نبود کتابخانهٔ تبلیغاتی
unzip -l mvpn-trial-arm64-51.apk | grep -iE "admob|fairbid|applovin|unityads|ironsource" || echo "none"

# ۴) فهرست آدرس‌های اینترنتی داخل APK (باید فقط managev1.xyz و منابع Firebase باشد)
strings app-release.apk | grep -oE "https://[a-zA-Z0-9.-]+" | sort -u | head -20
```

اگر چیزی خارج از این فهرست دیدید، آن را به‌عنوان باگ گزارش کنید.
